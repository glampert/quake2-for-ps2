Quake II for the PlayStation 2 - release @VERSION@
==================================================

An unofficial, fan-made port of id Software's Quake II to the Sony
PlayStation 2, built entirely with the free PS2DEV SDK.

  Project home:  https://github.com/glampert/quake2-ps2
  Source code:   https://github.com/glampert/quake2-ps2/tree/@COMMIT@
                 (the exact commit these ELFs were built from)

This package contains only the program. It does not contain the Quake II
game data (the pak files, music and videos), which is not free software:
you need your own copy of the game. See the project page for how to set
up the baseq2/ folder and run the game on a console or in PCSX2.
